# 播放列表与持久化

侧栏顶部切换列表，`+` 新建，`⋯` 管理列表名称、顺序和独立的播放模式。
单击只选择并检查媒体，双击、Enter 或右键 Play 才启动播放。Ctrl/Cmd 切换多选，Shift 选择连续范围，
列表获得键盘焦点或鼠标位于列表内时支持全选、Delete 和 Enter。多选拖拽保留所选条目的相对顺序；
菜单另提供上下移动及跨列表复制、移动。添加文件和重新定位使用异步文件选择器。

浏览焦点、播放来源和列表成员关系分别建模。浏览 B 时，底部播放控制和场景继续跟随 A。
底部歌曲按钮返回播放来源列表。移除当前条目后保留已打开媒体，下一首锚点指向删除位置之后的首个剩余条目；
锚点再次被移除时沿原顺序前进，重排则保留锚点身份。删除来源列表后暂停和定位仍然有效，曲终停止。
复制会跳过目标已有媒体；移动会在同一事务内合并目标重复项并删除源成员关系。任何操作都不删除媒体文件。

不可读取或无法解码的条目保留在列表中，右键可重试或重新定位。重新定位更新该媒体的所有列表引用；
若目标已经是另一个库条目，则提示使用已有条目，避免隐式改变成员关系。自动连播遇到失败媒体时尝试下一项，
同一轮不会反复重试已经失败的条目。输出设备故障仍交给原有设备恢复机制处理。

## 数据位置与格式

沿用应用 ID `com.macinrender.macindecode-ac4-player` 对应的 eframe 数据目录：

- macOS：`~/Library/Application Support/com.macinrender.macindecode-ac4-player/`
- Windows：`%APPDATA%/com.macinrender.macindecode-ac4-player/data/`
- Linux：`${XDG_DATA_HOME:-~/.local/share}/com.macinrender.macindecode-ac4-player/`

`library.sqlite3` 保存媒体、列表、条目、每张列表的焦点/滚动锚点/播放模式，以及当前来源与断点。
`settings.json` 保存已成功应用的输出设置、音量、静音、相机、编号显示、手动头部朝向和上次目录。
传感器实时姿态、解码缓冲与多选集合不落盘。`app.ron` 继续由 eframe 管理窗口状态。
测试可使用 `MACINDECODE_PLAYER_DATA_DIR` 指定独立数据目录；它同时隔离业务数据和 eframe 存档。
数据目录由操作系统文件锁保护，同一目录只允许一个实例写入。

SQLite 使用 bundled SQLite、外键、WAL 和 `synchronous=FULL`。ID 使用不复用的整数主键；
路径在工作线程中规范化，使用本机无损编码存储，数据库会拒绝其他操作系统的路径格式。
跨列表操作、排序以及由成员关系变化引起的播放锚点修复一起提交，UI 在成功回执后更新正式列表。
较晚到达的 UI 断点写入不能重新附着已经移除的条目。

JSON 带独立版本号，使用同目录临时文件、同步和原子替换，保留 `.bak`。
损坏文件有可用备份时先保留损坏原件再恢复；没有可用备份或版本来自新程序时禁止覆盖。
首次没有新配置文件时导入旧 eframe 输出设置、设备偏好和相机，之后不再写旧业务键。
数据库 v1 是首次引入的格式；未知版本或损坏数据库保留原文件并显示错误，未来的非空版本迁移必须先通过
SQLite backup API 备份（包括已提交的 WAL 内容），再在事务内升级。

## 线程与恢复

`library::LibraryController` 使用命令/回执连接专用工作线程，SQLite 连接不离开该线程。
只加载当前浏览和当前播放两个列表的轻量不可变快照，同一列表共享 `Arc`；其他列表只读取摘要。
绘制使用虚拟行，焦点和排序使用条目 ID，批量去重与选择使用集合。只在新快照到达时协调多选集合，
不会在每帧扫描五万条选择。单个媒体的错误标记以增量事件更新，复用现有列表快照，避免连续失效文件触发整表重载。完整检查报告最多缓存最近 16 份。

配置与浏览状态变更合并 500 ms；断点每 5 s 保存，暂停、切歌及正常退出额外保存。
计时位于 `App::logic`，最小化后仍运行。退出排空已接收的存储操作。
断点来自匹配当前解码 request/epoch 的输出播放头，并保存采样率、文件长度与修改时间。
启动恢复等待后台 seek 索引，恢复完成前不使用启动阶段的零进度覆盖旧断点；主动播放或定位取消旧恢复。
文件变化、已播完或无法定位时从头准备并保持暂停；文件缺失时保留断点与条目供重试。

## 验证

常规 `cargo test` 覆盖持久化事务、失败回滚、原生路径、旧配置迁移、损坏保护、稳定续播锚点、
异步查询顺序、浏览/播放隔离以及默认和最小窗口尺寸下的侧栏标题与状态文字裁剪。

容量与真实媒体测试按需运行：

```sh
cargo test capacity_one_hundred_thousand_entries -- --ignored --nocapture
cargo test large_library_ui_render_capacity -- --ignored --nocapture
# 设置项目构建所需的 MACINDECODE_AC4_SPEC_DIR，并指定本地 AC-4 样本：
cargo test real_playback_browse_pause_and_restart -- --ignored --nocapture
```

容量测试建立总计十万条、单列表五万条的数据，测量添加、加载、复制和重排。
真实媒体恢复测试使用静音定时输出，断言恢复后的输出采样帧与保存位置一致。
M3U8 导入导出不属于本版本。
